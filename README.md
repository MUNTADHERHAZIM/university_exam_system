### 📤 الاستيراد الجماعي الذكي (Bulk Import)
- **Excel Support**: دعم كامل لرفع مئات الأسئلة عبر ملفات Excel بضغطة واحدة.
- **Word Support**: إمكانية تحليل ملفات Word واستخراج الأسئلة منها آلياً.
- **Multi-Type**: دعم استيراد الاختيار من متعدد، الصح والخطأ، والأسئلة المقالية.

### 🛡️ نظام المراقبة المتطور (Advanced Proctoring)
- **Webcam Snapshots**: التقاط صور دورية وعشوائية للطالب أثناء الاختبار ورفعها للمراقب.
- **Anti-Cheat Lock**: رصد محاولات تغيير التبويب، تصغير النافذة، أو الخروج من وضع ملء الشاشة.
- **Violation Logging**: تسجيل آلي لجميع المخالفات (النسخ، اللصق، أدوات المطور F12) مع توقيت الحدوث.

### ⏱️ الحفظ التلقائي والمزامنة (Smart Auto-Save)
- **Server Sync**: حفظ الإجابات في قاعدة البيانات كل **10 ثوانٍ** لضمان عدم ضياع مجهود الطالب.
- **Offline Resilience**: دعم الحفظ المحلي (LocalStorage) لضمان الاستمرارية حتى عند انقطاع الإنترنت المفاجئ.

### 📊 لوحة التحكم والمراقبة المباشرة
- **Live Monitor**: متابعة حية لتقدم الطلاب، زمنهم المتبقي، وعدد مخالفاتهم.
- **Snapshot Gallery**: معرض صور لكل طالب لمراجعة سلوكه أثناء الاختبار.
- **Direct Chat**: نظام دردشة فوري بين المراقب والطالب للاستفسارات والتحذيرات.

## 🚀 البدء السريع (Quick Start)

### 1. المتطلبات (Requirements)
- Python 3.9+
- Django 4.2+
- المكتبات الإضافية: `openpyxl`, `python-docx`, `pillow` (موجودة في `requirements.txt`)

### 2. التثبيت (Installation)
```bash
# 1. تثبيت المكتبات
pip install -r requirements.txt

# 2. تهيئة قاعدة البيانات
python manage.py makemigrations
python manage.py migrate

# 3. إدخال البيانات التجريبية
python manage.py seed_data

# 4. تشغيل النظام
python manage.py runserver
```
